# ProVet 
> Sistema de gestión integral para clínicas veterinarias. Proyecto desarrollado por el grupo 1 4A 2026

## Descripción
ProVet es una herramienta diseñada en **Java** para optimizar el control de pacientes, citas y expedientes médicos en veterinarias locales de Xalapa. El objetivo es digitalizar procesos que actualmente se llevan de forma manual.

## Tecnologías utilizadas
* **Lenguaje:** Java 17+
* **IDE:** NetBeans 26
* **Gestor de BD:** Aun sin definir
* **Control de versiones:** Git & GitHub

##  Instalación y ejecución
1. **Clonar el repositorio:**
   `git clone https://github.com/Not-Abad/PatitasCare.git`
2. **Abrir en NetBeans:**
   File > Open Project > Seleccionar la carpeta `ProVet`.
3. **Configurar base de datos:** Actualmente no tenemos BD, se configurara en proximas versiones

---

##  Reglas para el equipo (IMPORTANTE)
Para que no rompamos el código, sigamos este flujo:

1. **PULL SIEMPRE:** Antes de empezar a programar cada día, haz un `git pull origin main`.
2. **TOKENS:** No uses tu contraseña de GitHub, genera un *Personal Access Token*.
3. **COMMITS:** Escribe mensajes claros (ej: `feat: agregar boton de registro`).
4. **NO SUBIR BINARIOS:** El archivo `.gitignore` ya está configurado, no lo borren.
